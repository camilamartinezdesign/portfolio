# portfolio

Portafolio de Camila Martínez. Sitio estático construido con [Vite](https://vite.dev).

```sh
npm install
npm run dev      # servidor de desarrollo
npm run build    # genera dist/
npm run preview  # sirve dist/
```

- `index.html` — marcado de la página
- `src/` — estilos, scripts y componentes
- `public/` — imágenes, media y CNAME
- `design-source/` — exportación original de Claude Design (solo referencia)
